****Technical Implementation Notes****

****Zendesk Travel Request Form****

The form structure will be adjusted to ensure that key travel details are captured clearly at the start of the request, reducing duplication and improving the overall user experience. The following fields will be moved to the bottom of the form: Subject and Detailed Description

The travel form architecture will change to the following: Travel Form

****Zendesk Ticket Fields****

Duplicate fields will be phased out to cater for the new workflow which only considers booking travel per trip.

The table below refers to the new fields which would be added to the existing set of Fields per traveler.
